# 月底展示与个人面试

队内通知要求月底展示学习笔记，或展示一个用所学知识完成的项目。两条路线任选其一作为主展示。每个人还会接受月底面试，考查实际掌握情况。具体日期、时长和评分口径以队内通知为准。下面是个人准备方案。

## 选定主展示

| 路线 | 展示内容 | 准备材料 | 面试时能现场演示 |
|---|---|---|---|
| A · 学习笔记 | 用一个问题串起推导、算例和纠错 | 一页目录，三份可追溯笔记，至少一份独立题解或仿真 | 白纸重列方程，翻出一次错误和修正证据 |
| B · 所学知识项目 | RC 低通练习板，从参数预测到制造文件 | 一页项目说明、手算、Multisim 工程与波形、EDA 源工程、DRC 和制造预览 | 打开工程定位测点与网络，现场改一个参数并解释结果 |

笔记路线可以选「双源网络的等效」「RC/RL 时域行为」「相量与复阻抗」三份材料。附上一页 EDA 和工艺学习记录，面试时有图可指。项目路线可以展示仿真和设计文件，明确做到哪一步，以及哪些结果来自计算、仿真或实测。RC 项目覆盖不了的直流网络定理、RL、器件与动力组件，单独准备白纸题和术语卡。

两条路线共用 [展示索引](portfolio.md)，把结论和证据文件一一对应。每个链接都用本地相对路径，答辩前离线打开检查一次。

## 个人面试模拟

自己先按 15 分钟练习。3 分钟展示，8 分钟抽题，4 分钟改参数或定位错误。可以请同学只读问题、不提示结论。实际面试按队内安排。

| 检查项 | 建议追问 | 准备证据 |
|---|---|---|
| 微积分及物理意义 | 电流对时间积分得到什么？RC 方程中各项是什么量、单位是什么？电流曲线翻倍时电压变化如何？ | 充电曲线、电荷手算和单位 |
| 直流列式与端口等效 | 选参考地后列 KCL。换成网孔法时公共支路怎么写？改负载后戴维南模型哪些量保持不变？叠加时受控源怎么处理？ | [双源题](../labs/checks.md) 的独立草稿 |
| 一阶动态 | 写 RC 与 RL 的初值、终值和时间常数。把电阻翻倍后分别有什么变化？ | 两张仿真曲线与预测值 |
| 相量与复阻抗 | 为什么同频正弦稳态中微分对应乘以 $j\omega$？给一个含电容的节点方程。方波能否用单个相量表示？ | 手推阻抗、复数方程和验证结果 |
| 元件、MCU 与动力 | MOSFET、BJT 和运放各举一个用途。画出 MCU、ESC、BLDC 和舵机的控制链与供电路径。 | 术语卡、功能框图 |
| EDA 与 PCB | 从原理图符号定位焊盘编号。DRC 通过后还需要看哪些制造层？指出一个工艺约束及来源。 | [PCB 验收记录](../labs/pcb.md) 对应截图或工程 |

自评每项 0–2 分。0 分表示卡住，1 分表示提示后能做，2 分表示能独立列式或定位，并解释原因。将 0、1 分的题写回 [掌握情况](../progress.md)，隔天换参数重做。面试之后记下实际被问到的内容、卡点、反馈和补做证据。

## 倒排准备

- 11/26 前选定主展示路线。收齐三条最能说明你掌握程度的证据。
- 11/27–29 完成展示索引，至少做一轮计时模拟。修正断链、错误读数和解释不清的地方。
- 11/30 用既定月末复盘时段做闭卷、展示和归档。若队内公布更早面试，按实际日期提前完成索引与模拟。
