| 状态   | 理想二极管模型     | 真实器件           |
| ---- | ----------- | -------------- |
| 正向导通 | 类似闭合开关，压降为零 | 存在正向压降和功率损耗    |
| 反向截止 | 类似断开开关，电流为零 | 通常有一定反向漏电流     |
| 反向过压 | 理想模型可忽略击穿   | 可能进入击穿，需看器件额定值 |

# 分类

## 按特性与用途

- | 类型             | 主要用途         | 特点                                                       |
  | ---------------- | ---------------- | ---------------------------------------------------------- |
  | **整流二极管**   | 将交流电整流     | 把交流电转换为**方向固定、但大小可能仍然波动的电压或电流** |
  | **开关二极管**   | 信号切换、钳位   | 常用于电流较小、切换较快的信号电路                         |
  | **肖特基二极管** | 电源整流、续流等 | 某些工作条件下正向压降较低、开关特性较快                   |
  | **稳压二极管**   | 稳压、参考或钳位 | 在规定条件下工作于反向击穿区                               |
  | **TVS 管**       | 抑制瞬态过电压   | 用于吸收或分担规定条件下的瞬态能量                         |
  | **LED**          | 发光、指示       | 正向工作时发光，需要控制电流                               |

## 按封装

- 直插（DO-41）【一般长脚为正极、短脚为负极】
- 贴片（SOD-123、SMA、SMB、SMC）【外壳上带有**色环、白环或黑环**的一端为**负极**，另一端为**正极**。】

**二极管的基本特性是单向导电：电流只能从阳极（+）流向阴极（−），反向截止。**

各类二极管的特性对比：

| 类型         | 代表型号         | 正向压降 | 反向恢复时间 | 特点与典型用途                     |
| :----------- | :--------------- | :------- | :----------- | :--------------------------------- |
| 整流二极管   | 1N4007 / M7      | 0.7~1.0V | µs 级        | 成本低，用于工频整流               |
| 开关二极管   | 1N4148           | 约 0.7V  | 4ns          | 速度快、电流小，用于信号级开关     |
| 肖特基二极管 | SS34、1N5819     | 0.3~0.5V | 极短         | 压降低、速度快，用于低压大电流续流 |
| 稳压二极管   | BZT 系列         | —        | —            | 工作于反向击穿区，用于稳压与限幅   |
| TVS          | SMAJ 系列        | —        | 极短         | 吸收浪涌，将瞬时高压钳位           |
| 发光二极管   | 0603 LED、WS2812 | 1.8~3.4V | —            | 通电发光，用于状态指示             |

- **肖特基二极管**：
  - **优点**：压降小、功耗低、效率高、开关速度快。
  - **缺点**：耐压低、漏电流大。
  - **适用场景**：低压、高频、大电流的场合（如高频开关电源的输出整流、DC-DC转换器、太阳能电池防倒灌、便携式设备的电池保护）。
- **普通二极管**：
  - **优点**：耐压高、反向漏电流小、成本低。
  - **缺点**：导通压降大，发热较多，不适合高频开关。
  - **适用场景**：工频交流整流（如50Hz/60Hz家用电源适配器）、高压整流保护电路。

# 重要电学参数

- **正向压降（ \(V_F\)）**：导通时的压降，直接决定导通损耗
  - \(V_F\) 是二极管在规定正向电流和温度条件下的端电压。
- **反向耐压**：可承受的最大反向电压，超过将被击穿
- **正向平均电流**：长期工作的电流上限
- **反向恢复时间**：由导通切换到截止所需的时间，开关频率越高越重要
- **反向漏电流**：截止时仍有微小电流流过，肖特基的漏电流较大且随温度显著增大
  - 二极管反向截止时，真实器件通常仍会有少量反向电流，这叫**反向漏电流**。

# 用途

- **续流**：开关管关断时，为电感电流提供通路（例如 Buck 电路中的续流二极管）

  - 主要作用：**在开关状态变化时，为电感电流提供设计好的通路，并帮助限制开关器件承受的电压。**
- **防反接**：串接于电源入口，防止电源接反损坏后级电路.

  - 电源极性正确时：二极管正向导通，后级获得供电。

    电源极性反接时：二极管处于反向状态，通常可阻止较大的反向电流。
- **整流**：将交流电转换为直流电

  - \[ \text{交流输入} \rightarrow \text{二极管整流} \rightarrow \text{脉动电压} \rightarrow \text{电容等滤波} \rightarrow \text{波动较小的电压} \]
  - 最简单的是**半波整流**：
    - 一个方向的半周，二极管可能导通；
    - 相反方向的半周，二极管通常截止。
- **钳位与保护**：配合 TVS、稳压二极管，抑制浪涌与过压

# 二极管的方向性

二极管是**单向导通**的：电流从阳极（+）流向阴极（−），**原理图上即三角形指向竖线一侧**。方向画反将导致电路板报废。

肖特基二极管导通压降只有 0.3V 左右（普通硅管 0.7V），因此在低压大电流场合（例如 Buck 的续流二极管）几乎为必选方案。
