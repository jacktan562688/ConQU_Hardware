## 使用方法

先合上卡片回答自测，再核对推导和条件；复测后记录真实日期、结果与错因。新增或更正学习笔记时更新对应卡片，保留来源。示波器笔记尚空，暂不据此建立已完成知识卡。复阻抗为原索引问题的补充推导，不标记为已掌握。
