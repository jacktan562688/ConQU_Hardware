# 本质

电感的本质是 **\(u_L=L\dfrac{di_L}{dt}\)**：电感两端的电压正比于电流的变化率，即**阻碍电流变化**——电流增大时产生反向电压，电流减小时维持电流。

电感电流要改变，就需要电感两端出现相应电压；在给定电压和电感量时，电流变化速度受到约束。

因此**电感可以平抑电流波动**，这是它在电源电路中最核心的作用。

| 符号                 | 含义                 | 单位                      |
| -------------------- | -------------------- | ------------------------- |
| \(u_L\)              | 电感两端电压         | 伏特 \(\mathrm V\)        |
| \(L\)                | 电感量               | 亨利 \(\mathrm H\)        |
| \(i_L\)              | 流过电感的电流       | 安培 \(\mathrm A\)        |
| \(t\)                | 时间                 | 秒 \(\mathrm s\)          |
| \(\dfrac{di_L}{dt}\) | 电流随时间变化的快慢 | 安培每秒 \(\mathrm{A/s}\) |

电感的对应关系：在电压有限的条件下，理想电感中的电流不能瞬间跳变。

由于在突然开关开关是，点干货提高自身电压来维持电流连续。所以继电器线圈、电机绕组等感性负载的开关电路中，常常需要设计**续流或吸收回路**。具体采用二极管、TVS 或其他方式。

| 比较项目       | 电容                      | 电感                             |
| -------------- | ------------------------- | -------------------------------- |
| 主要储能形式   | 电场                      | 磁场                             |
| 基本关系       | \(i_C=C\dfrac{du_C}{dt}\) | \(u_L=L\dfrac{di_L}{dt}\)        |
| 在相应量有限时 | 电流有限 → 电压不能突变   | 电压有限 → 电流不能突变          |
| 理想直流稳态   | 电流为零，表现为开路      | 两端电压为零，表现为短路         |
| 真实器件       | 有漏电、ESR、寄生电感等   | 有绕组电阻、寄生电容、磁芯损耗等 |

由于在直流稳态中，电流不会再发生变化，所以电流的变化量就是零。此时理性电感两端的电压等于零。故相当于短路。



# 怎么读

## 常见单位：

| 单位             | 名称 | 换算                                  |
| ---------------- | ---- | ------------------------------------- |
| \(\mathrm H\)    | 亨利 | 基本单位                              |
| \(\mathrm{mH}\)  | 毫亨 | \(1\ \mathrm H=1000\ \mathrm{mH}\)    |
| \(\mu\mathrm H\) | 微亨 | \(1\ \mathrm{mH}=1000\ \mu\mathrm H\) |
| \(\mathrm{nH}\)  | 纳亨 | \(1\ \mu\mathrm H=1000\ \mathrm{nH}\) |

## 电感丝印的读法

- 带 `R` 的，`R` 即小数点：`4R7` = **4.7µH**，`6R8` = **6.8µH**，`3R3` = **3.3µH**，`2R2` = **2.2µH**，`1R5` = **1.5µH**，`R47` = **0.47µH**
- 三位纯数字：前两位是有效数字，第三位是 10 的幂。`470` = **47µH**，`100` = **10µH**

不同厂家对三位数字的单位定义（µH 或 nH）可能不同，比如线艺电感的单位为 nH，**应以数据手册为准**。

# 电学参数

## **电感量及容差**

但实际电感量还可能随：

- 测试频率；
- 直流偏置电流；
- 温度；

等条件变化。

## **电感直流电阻（DCR）**

真实电感绕组不是完美导线，有一定电阻，称为**直流电阻 DCR**。

线圈本身的电阻。DCR 越小越好，因为 DCR 上的损耗为 \[ P_{\text{铜损}}\approx I_{\mathrm{RMS}}^2R_{\text{DCR}} \]，会造成铜损，直接转化为热量

## **饱和电流\(I_{\text{sat}}\)及电感衰减曲线**

对于有磁芯的电感，随着电流增加，磁芯可能逐渐接近饱和状态，导致**增量电感下降**。

电流增大到一定程度后磁芯饱和，电感量急剧下降。饱和电流（Isat）通常指电感量降至标称值 70%~80% 时的电流

## 温升电流（Irms）

温升电流常用于说明：在规定测试环境下，电流造成器件温度上升到某一程度时的电流值。

| 参数     | 主要关心                         |
| -------- | -------------------------------- |
| 饱和电流 | 电流增大后，电感量下降到什么程度 |
| 温升电流 | 电流导致器件发热到什么程度       |

## 自谐振频率（SRF）

真实电感内部有寄生电容，因此它并不是在所有频率下都表现为理想电感。

超过该频率后，电感将呈现电容特性

# 用途

## **滤波**：抑制电流的快速变化

- 与电容配合，抑制开关电源输出的纹波

- 电感与电容经常配合使用：

  - 电感的电流不能在有限电压下瞬间变化；
  - 电容的电压不能在有限电流下瞬间变化。

  因此，合适的 LC 网络可以帮助抑制电流、电压中的部分波动。

## 储能和传递能量

在开关电源中，电感电流会随开关状态周期性变化，磁场能量也随之变化。

## **延迟**

- 电感阻碍电流变化，因此电流不会突变，天然具有延迟效果

***一般在 buck 、boost 电路中使用***

Buck 电路中的电感选型

- **电感量**：决定纹波电流的大小，一般使纹波电流处于输出电流的 20%~40%
- **饱和电流**：应大于峰值电流（= 输出电流 + 一半纹波电流）
- **DCR**：越小效率越高，但通常体积与成本也越高
