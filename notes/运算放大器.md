# 运算放大器基础

## 符号与引脚

运放（即运算放大器）的电路符号是一个三角形：两个输入端、一个输出端

- 同相输入端：输出随它同相变化
- 反相输入端：输出随它反相变化

                           正电源 V+
                              │
                         ┌────┴───┐
    同相输入 V₊ ─────────  ┤ +      │
                         │   运放  ├──── 输出 Vout
    反相输入 V₋ ────────  ─┤ −      │
                         └────┬───┘
                              │
                           负电源 V−
| 符号                    | 含义               |
| ----------------------- | ------------------ |
| 输入端 \(V_+\)、\(V_-\) | 运放比较的两个电压 |
| 电源端 \(V^+\)、\(V^-\) | 给运放供能的电源   |

**简化模型：**

\[ \boxed{V_{out}=A_{OL}(V_+-V_-)} \]

- \(V_+-V_-\)：两个输入端的电压差；
- \(A_{OL}\)：开环增益，可以理解为“没有外部反馈时的放大倍数”。
- 因为输出侧放电受到电源的限制，所以要考虑是否进入饱和状态

**开环时，运放增益很大，输入稍有差别，输出就容易冲到某一侧极限。输出电位无法超出电源轨**

## 负反馈调节

**电压跟随器:**

                         ┌─────────┐
     输入 Vin ────────────┤ +       │
                         │   运放   ├────┬──── 输出 Vout
                     ┌───┤ −       │    │
                     │   └─────────┘    │
                     └──────────────────┘
                          输出接回反相端
输出偏低 → 推高输出
输出偏高 → 压低输出

**反馈产生的作用抵消了原来的偏差，这就叫负反馈。**

在工作范围允许、环路稳定的条件下，输出最终接近：

\[ \boxed{V_{out}\approx V_{in}} \]

## 两条基本准则

理想运放有两条准则，它们是分析一切运放电路的出发点。

**准则一：虚短。** 开环增益 AOL为无穷大，而输出电压是有限的，因此两输入端之间的电压差必趋于零：

让：\[ \boxed{V_+\approx V_-} \]

“虚”的意思是：**电压近似相等，但两个输入端并没有被导线短接。**

根据基本公式：

\[ V_+-V_-=\frac{V_{out}}{A_{OL}} \]

> 虚短只在负反馈成立时才成立
>
> **虚短不是运放自身固有的性质，而是负反馈的结果。**
>
> 若接成正反馈（反馈回到同相端），运放会迅速冲到电源轨并保持，此时 V+ ≠ V−，虚短不再成立。这与"线性稳压器反馈极性接反则稳压失败"是同一个道理。

**准则二：虚断。**输入阻抗为无穷大，因此两个输入端都不消耗电流：

\[ \boxed{I_+=I_-=0} \]

输入端想成一个“几乎不取电流的电压观察点”。

| 概念 | 近似关系                   | 含义                                 |
| ---- | -------------------------- | ------------------------------------ |
| 虚短 | \(V_+\approx V_-\)         | 正常线性负反馈时，两输入电压近似相等 |
| 虚断 | \(I_+\approx I_-\approx0\) | 输入端几乎不取电流                   |

**虚短说电压，虚断说电流。**

## 闭环增益由外接电阻决定

在负反馈条件下，输出电压只取决于外接电阻的比值，与运放本身几乎无关：

**增益**就是输出与输入的比值：

\[ A_v=\frac{V_{out}}{V_{in}} \]

**闭环**是指输出通过反馈网络，回到输入端，形成一个环路：

```
`输入 → 运放 → 输出`
        `↑       │`
        `└─反馈──┘`
```

### 同相放大器：接入相同相端、反馈分压回反相端

```
                       ┌─────────┐
Vin ───────────────────┤ +       │
                       │   运放  ├───────┬── Vout
                  ┌────┤ −       │       │
                  │    └─────────┘       │
                  │                      │
                  └──────── Rf ──────────┘
                  │
                  Rg
                  │
                 GND
```

- 同相端：接输入 \(V_{in}\)。
- 反相端：接两只电阻的中点。**反相端收到的是输出的一部分。**
- 输出端：接 \(R_f\) 的另一端。
- 输出电压：Vout=Vin(1+Rf*/*R1)

### 反相放大器：输入经电阻接反相端

```
                         Rf
                  ┌────/\/\/───────┐
                  │                │
Vin ── Rin ───────●────┤−          │
                       │   运放 ───┴── Vout
GND  ──────────────────┤+
```

这个反相端节点叫**虚地**：电压接近地，但没有直接接地。

输入电阻上的电流：

\[ I_{in}=\frac{V_{in}-0}{R_{in}} \]

由虚断，这股电流几乎不进入运放，因此经 \(R_f\) 流向输出：

\[ I_f=\frac{0-V_{out}}{R_f} \]

令两者相等：

\[ \frac{V_{in}}{R_{in}} =\frac{-V_{out}}{R_f} \]

得到：

\[ \boxed{V_{out}\approx-\frac{R_f}{R_{in}}V_{in}} \]

### 电压跟随器：输出直连反相端

跟随器直接把输出接回反相端：

\[ V_-=V_{out},\qquad V_+=V_{in} \]

由虚短：

\[ \boxed{V_{out}\approx V_{in}} \]

由此可得两条推论：其一，**输出电压的精度由基准精度与电阻精度决定，而不是由运放的增益决定**；其二，环路增益越高，稳态误差越小，输出就越接近设计值。

| 电路       | 输入接法                     | 闭环增益        | 输入阻抗         |
| ---------- | ---------------------------- | --------------- | ---------------- |
| 同相放大   | 输入接同相端                 | \(1+R_f/R_g\)   | 理想情况下无穷大 |
| 反相放大   | 输入经电阻接反相端           | \(-R_f/R_{in}\) | 约为 \(R_{in}\)  |
| 电压跟随器 | 输入接同相端，输出直连反相端 | 1               | 理想情况下无穷大 |

## 真实运放的非理想特性

| 参数             | 含义                                        | 对设计的影响                                                 |
| :--------------- | :------------------------------------------ | :----------------------------------------------------------- |
| 开环增益 AOL     | 直流下的裸增益，通常 十的五次方到十的七次方 | 有限即存在稳态误差，**AOL**越大输出越准<br />**开环增益越大，负反馈通常越能把输入差压压小；但“越大越好”仍要以环路稳定为前提。** |
| 增益带宽积 GBW   | AOL(f) ⋅ f 近似为常数                       | 闭环增益越高，可用带宽越窄、响应越慢                         |
| 压摆率 SR        | 输出电压的最大变化速率                      | 限制负载突变后输出电压的恢复速度                             |
| 输入失调电压 VOS | 使输出为零所需的等效输入补偿                | 直接叠加为输出的直流误差                                     |
| 电源抑制比 PSR   | 抑制电源波动传导至输出的能力                | 决定输入端的纹波有多少漏到输出                               |
| 输入共模范围     | 两输入端可正常工作的电位区间                | **单电源场合的首要限制**，多数运放无法处理接近地或接近 VCC 的信号 |
| 输出摆幅         | 输出可达到的最高 / 最低电位                 | 无法到轨时，射极跟随器方案可能推不动通路管                   |

### 轨到轨**（Rail-to-Rail）**

标注 R2R 输入 / 输出的运放，其共模范围与输出摆幅可以贴近电源轨

- 轨到轨输入：输入范围可以接近两条电源轨。
- 轨到轨输出：输出可以接近两条电源轨。

两者是不同能力；“接近”也不等于任意负载下都能完全达到。

## 在线性稳压器中扮演的角色

误差放大器就是运放，其任务是把 Vfb 与 Vref 的差值放大后去驱动通路管。由此可以直接读出若干设计要求：

- **直流精度**：AOL越大，稳态下 VFB越接近 VREF，输出越准；运放的 VOS与温漂则会原样叠加到输出上
- **动态响应**：GBW 与 SR 决定负载跳变后输出恢复稳定的快慢
- **纹波抑制**：输入端的纹波经通路管传至输出，运放的 PSRR 越差、AOL 越低，漏过去的越多
- **供电来源**：运放由 VIN供电，因此输入电压下限不仅受通路管压差限制，还受运放的最低工作电压与输出摆幅限制
