# 分类

## 按照电阻体材料分类

| 类型                 | 初步认识                               | 常见关注点                         |
| -------------------- | -------------------------------------- | ---------------------------------- |
| **厚膜电阻**         | 通过厚膜工艺制成，通用贴片电阻中很常见 | 成本、阻值范围、容差、温度系数     |
| **薄膜电阻**         | 通过薄膜工艺形成电阻层                 | 某些产品适合较高精度或较低温漂要求 |
| **金属膜电阻**       | 电阻体使用金属膜，直插电阻中常见       | 精度、稳定性和噪声等               |
| **线绕电阻**         | 使用电阻丝绕制                         | 功率能力，以及绕线带来的寄生电感等 |
| **金属合金采样电阻** | 常见于低阻值电流检测                   | 阻值、温漂、功率和连接方式         |

## 按封装

| 类型         | 安装方式                | 常见例子              |
| ------------ | ----------------------- | --------------------- |
| **直插电阻** | 引脚穿过 PCB 的孔后焊接 | 色环电阻              |
| **贴片电阻** | 焊接在 PCB 表面的焊盘上 | 0603、0805、1206 电阻 |

## 按阻值是否能够改变

| 分类     | 意思                                       | 例子                         |
| -------- | ------------------------------------------ | ---------------------------- |
| 固定电阻 | 标称阻值不由使用者主动调节                 | 常见 1 kΩ 贴片电阻           |
| 可调电阻 | 可以通过旋钮或滑动结构调整阻值             | 电位器、微调电阻             |
| 特殊电阻 | 阻值或伏安特性与温度、电压、光照等条件有关 | 热敏电阻、压敏电阻、光敏电阻 |

# 怎么读

## **贴片电阻丝印的读法**

- 三位数字：前两位是有效数字，第三位是 10 的幂。`103` = 10×10³ = **10kΩ**，`472` = 47×10² = **4.7kΩ**
- 四位数字（±1% 精度常用）：`1001` = 100×10¹ = **1kΩ**，`4702` = 470×10² = **47kΩ**
- `0` 或 `000` = **0Ω**（并非没有电阻，而是阻值接近 0）
- 中间带 `R` 的，`R` 即小数点：`4R7` = **4.7Ω**，`R10` = **0.1Ω**

## **型号命名解读**

以 `FRC0603F1001TS` 为例：

- `FRC` —— 富捷（FOJAN）的厚膜电阻系列
- `0603` —— 封装尺寸（按照**英制尺寸代码**）
- `F` —— 精度 **±1%**（±5% 的代码为 `J`）
- `1001` —— 阻值代码，即 1kΩ
- `T` —— 包装方式（编带）

## 厚膜贴片电阻的组成：

| 部分           | 作用                   |
| -------------- | ---------------------- |
| 陶瓷基板       | 提供机械支撑和绝缘基础 |
| 电阻体         | 形成主要的电阻特性     |
| 保护层         | 保护电阻体             |
| 两端端头及镀层 | 便于与焊盘连接和焊接   |

# 电学参数

## 电阻差及容差

- 常见容差 ±1% ±5%

- E24（±5% 常用）/ E96（±1% 常用）阻值系列，选型时重要参考

  - 实际生产中，电阻常采用**优选数值系列**，例如：

    - E24：每个十倍范围内有 24 个基本标称值；
    - E96：每个十倍范围内有 96 个基本标称值。

    E24 常和较宽容差产品一起出现，E96 常见于较精密的产品，但**系列和容差不是绝对绑定关系**。

- 容差是厂家在规定条件下对阻值偏差的要求。即电阻阻值并非任意取值，只能在标准系列中选择最接近的规格

## 额定功率与功率衰减曲线

- 0603 约 100mW，0805 约 125mW，1206 约 250mW，2512 约 1W
- 数据手册中的**功率降额曲线**会说明：随着规定的环境温度或其他条件变化，允许耗散的功率如何变化。具体以厂家曲线定义为准。
- 环境温度越高，可承受的功率越低，这条曲线即**功率衰减曲线**

- 功率需留余量
  - 电阻的实际功耗不应超过额定功率的 **50%~70%**。0603 标称 100mW，实际功耗最好控制在 50mW 以内——超出后温升明显，阻值也会随之漂移。

## 温度系数 TCR

TCR 表示电阻值随温度变化的程度，单位常写为：\[ \mathrm{ppm}/^\circ\mathrm C \]

其中：\[ 1\ \mathrm{ppm}=10^{-6} \]

精密电路应选用低温漂型号

## 寄生参数

理想电阻只有电阻特性；真实电阻由于材料、形状、端头、焊盘和 PCB 走线等，还会出现一定的**寄生电感和寄生电容**。

“寄生”的意思是：设计者本来主要想用它的电阻功能，但实际结构中还会伴随其他电学特性。

# 用途

## 分压电阻

 A["输入电压 Vin"] --> R1["上方电阻 R1"]  --> O["输出 Vout"] --> R2["下方电阻 R2"] --> G["GND"]

- 两个电阻串联，**将电压按比例分出**。例如将 24V 分压后送入仅能测量 3.3V 的 ADC

## 限流电阻

- **限流电阻**：利用电阻产生压降，限制回路中的电流。
- 为 LED、三极管基极串联电阻，防止电流过大损坏器件、过 Vsam 的电压，测量出R1两端的电压差实现电压保护功能达到阈值时，调整或关断 Q1。

## 采样电阻

- **采样电阻**：利用电流流过电阻时产生的电压，来了解电流有多大。
- 实际采样电阻要权衡：
  - 阻值大：采样电压较大，通常更容易测量，但压降和损耗也更大；
  - 阻值小：损耗较小，但采样信号也较小。

## 测温电阻

- 热敏电阻测量压敏电阻、防浪涌保护

## 上拉和下拉电阻

- 为信号线提供确定的电平
- 数字芯片的输入引脚**不能悬空**，否则电平不确定、易受干扰。上拉即将引脚通过电阻接至电源（默认高电平），下拉即接至地（默认低电平）。**I2C 的 SDA/SCL 必须各接一个上拉电阻**，否则总线无法正常工作。

### 上拉电阻

- 按钮未按下：节点默认为高电平；
- 按钮按下：节点被拉到低电平。
  - 电阻的作用是让节点有默认高电平，同时在按钮按下时限制从电源到地的电流。
- 将输入节点通过电阻连接到电源：
  - 电源 → 上拉电阻 → 输入节点

### 下拉电阻

- 将输入节点通过电阻连接到 GND。没有其他驱动时，节点默认为低电平；当其他电路把它拉高时，它可以变为高电平。

## 阻性匹配：减少快速信号反射

- 在高速信号线末端接入匹配电阻，减少信号反射

- 当信号边沿非常快、走线相对边沿传播距离不可忽略时，PCB 走线需要按传输线考虑。

  如果信号到达线路末端时，负载阻抗与传输线特性阻抗不合适，可能产生反射。合理的终端电阻可以帮助降低反射。

## **0Ω 电阻的用途**

- **配置电路**：通过是否焊接来选择某个功能路径。

- **调试隔离**：拆掉后断开线路，便于排查。

- **预留修改位置**：便于后期断开线路测量电流或增补器件

- **辅助布线**：作为**跳线**使用，跨接无法布通的走线

- 实现**单点接地**，将模拟地与数字地在一点连接

  - **模拟地**，常标为 **AGND**：关联传感器、运放、ADC 模拟输入等电路。

    **数字地**，常标为 **DGND**：关联 MCU 数字逻辑、时钟、数字通信等电路。

    | 比较         | 模拟电路                 | 数字电路                               |
    | ------------ | ------------------------ | -------------------------------------- |
    | 常处理的信号 | 连续变化的电压或电流     | 逻辑高、逻辑低等离散状态               |
    | 常见关注点   | 微小误差、噪声、测量精度 | 时序、电平、信号完整性                 |
    | 地相关问题   | 参考点波动可能影响测量   | 快速变化的返回电流可能引起局部电压波动 |

# 选择

| 步骤        | 要回答的问题                               |
| ----------- | ------------------------------------------ |
| 1. 阻值     | 电路计算需要多少欧？                       |
| 2. 容差     | 偏离标称值多少仍可接受？                   |
| 3. 功率     | 实际最大功耗是多少？温度下允许多少？       |
| 4. 电压     | 电阻两端的工作电压、瞬态电压是否满足要求？ |
| 5. 温度系数 | 温度变化会不会明显影响精度？               |
| 6. 封装     | PCB 空间、焊接和散热条件是否合适？         |
| 7. 特殊需求 | 是否需要低阻采样、脉冲承受能力或高频性能？ |



# 其他（浪涌、伏安特性等）

- 什么是浪涌？浪涌是电路中的电压或电流，在很短时间内出现的异常冲击。
- L-火线；N-零线
- **R1的伏安特性是非线性的，电压升高时电流会急剧增大**。
- **浪涌**：通常持续时间很短，例如一个瞬态脉冲。
- **持续过电压**：电压异常升高并维持较长时间。
- **什么叫“钳位电压”？** 在规定浪涌波形和电流条件下，压敏电阻两端出现的电压水平。
