# MOSFET

金属氧化物半导体场效应晶体管：一种常用于电路中的**电子开关**

G、D、S 三个端子

| 缩写  | 英文   | 中文 | 入门理解       |
| ----- | ------ | ---- | -------------- |
| **G** | Gate   | 栅极 | 控制端         |
| **D** | Drain  | 漏极 | 电流进出的通道 |
| **S** | Source | 源极 | 电流进出的通道 |

\[ \boxed{V_{GS}=V_G-V_S} \]

其中：

- \(V_G\)：栅极电位；
- \(V_S\)：源极电位；
- \(V_{GS}\)：**栅极相对于源极的电压**。

分类：

- N 沟道 MOSFET（NMOS）
- P 沟道 MOSFET（PMOS）

| 类型 | 栅源电压的入门判断                            | 常见用途                     |
| ---- | --------------------------------------------- | ---------------------------- |
| NMOS | \(V_{GS}\) 为合适的正电压时，可以形成导电通道 | 低边开关、电机驱动、电源开关 |
| PMOS | \(V_{GS}\) 为合适的负电压时，可以形成导电通道 | 一些高边开关、电源路径控制   |

导通条件：

- **NMOS**：栅源电压\(V_G\)大于阈值电压\(V_S\)时导通，电流从 D 流向 S
- **PMOS**：栅极电位低于源极\(V_{GS}\)时导通，电流从 S 流向 D
- 完全导通后，D 与 S 之间等效为一个很小的电阻 

关键参数

| 参数           | 含义               | 选型时要问                                 |
| :------------- | :----------------- | :----------------------------------------- |
| \(V_{DS}\)     | 漏源电压额定值     | 关断时及瞬态下，漏源电压是否在允许范围内？ |
| \(V_{GS}\)     | 栅源电压额定范围   | 栅源电压是否可能正向或负向超限？           |
| \(I_D\)        | 漏极电流相关额定值 | 在实际温度和散热条件下能否满足？           |
| \(R_{DS(on)}\) | 导通电阻           | 在实际驱动电压和温度下损耗是多少？         |
| \(V_{GS(th)}\) | 栅源阈值电压       | 不要把它当成大电流充分导通的保证           |

**栅极不得悬空**

MOSFET 的栅极是高阻抗的，悬空时极易受干扰而误导通。因此栅极**必须有确定的状态**：串接一个电阻或 TVS 接至源极

**选型主要关注两类损耗**

- **导通损耗**：应选择较小的型号
- **开关损耗**：与 Qg和开关频率有关，频率越高越明显，因此应选择 Qg** 较小的型号

低压大电流场合（例如电源切换、电机驱动）主要关注；高频开关场合则需重点考虑 Qg。两者通常相互制约，应按实际需求权衡。

#### 用途

- **开关**：以小电压控制大电流回路的通断。RM 上常用于替代继电器、实现过流保护与电源切换
- **负载**：作为功率级的核心器件，驱动电机、电磁线圈等大功率负载



**为何不能由 MCU （推挽/开漏）直接驱动**

MCU 的 IO 引脚一般只能输出几十 mA，而电机、电磁铁动辄数安。因此 MCU 仅负责发出控制信号，实际承担功率输出的是 MOSFET。
