# 一、类型

## 按电介质和结构分类

|类型|常见外观|是否有极性|主要特点|常见用途|
|---|---|---|---|---|
|**陶瓷电容**|小型贴片或圆片|通常无极性|体积小，种类多；不同陶瓷材料特性差别较大|芯片去耦、高频滤波、信号处理|
|**铝电解电容**|常见为圆柱形|通常有极性，也有无极性型号|较容易做到较大容量，但要关注寿命、漏电和 ESR|电源滤波、储能|
|**钽电解电容**|常见为贴片块状|通常有极性|在一定体积下可获得较大容量；对工作条件较敏感|电源滤波、局部储能|
|**薄膜电容**|方盒状或圆柱状|通常无极性|稳定性、损耗等特性因薄膜材料而异|信号处理、电源和交流电路|
|**云母电容**|小型封装或片状|通常无极性|**稳定性较好**，常见容量较小|高频、振荡和精密电路|
|**超级电容**|纽扣形、圆柱形等|多数有极性，具体看型号|容量很大，单体额定电压通常较低|短时储能、备用供电|

X、Y 是按**安全用途和认证要求**划分的类别，并不单独说明它的电介质材料、容量和具体适用条件。

| 分类             | 常见连接位置                                                 | 主要关注                               |      |      |
| ---------------- | ------------------------------------------------------------ | -------------------------------------- | ---- | ---- |
| **X 类安规电容** | 常跨接在 L、N 之间                                           | 满足跨线使用的安全要求，并参与干扰抑制 |      |      |
| **Y 类安规电容** | 常用于线路与可触及导电部分、保护地，或隔离电源的相关隔离屏障之间；具体看设计 | 对绝缘和失效安全有相应要求             |      |      |

## 按“有没有极性”分类

### 1. 无极性电容

通常不要求固定正负极方向，常见于：

- 陶瓷电容；
- 薄膜电容；
- 云母电容；
- 特定设计的无极性电解电容。

但**无极性不等于没有耐压限制**。仍要核对交流或直流使用条件、额定电压等。

### 2. 有极性电容

通常要求按规定方向连接，常见于：

- 普通铝电解电容；
- 普通钽电解电容；
- 多数超级电容。

**电解电容有极性，反接将导致损坏**

- 直插的：**长脚为正极**，外壳上标有 `-` 的色带一侧为负极
- **贴片的：色带 / 缺口一侧为负极**
- 反接轻则导致鼓包漏液，重则直接爆裂。

## 按“安装方式”分类

### 1. 直插电容

有引脚，通常插入 PCB 孔中焊接。

常见例子：

- 圆柱形铝电解电容；
- 圆片陶瓷电容；
- 部分薄膜电容。

### 2. 贴片电容

直接焊接在 PCB 表面的焊盘上。

常见例子：

- 贴片多层陶瓷电容；
- 贴片钽电容；
- 部分贴片铝电解电容。

## 按“容量能否调整”分类

| 分类         | 含义                             | 常见用途           |
| ------------ | -------------------------------- | ------------------ |
| **固定电容** | 标称容量在使用中不由用户机械调整 | 去耦、滤波、储能等 |
| **可变电容** | 可以通过机械结构等方式调整容量   | 某些调谐电路       |
| **微调电容** | 可在较小范围内调整容量           | 校准振荡频率等     |

# 二、什么是电容？

电容器是由两个相互绝缘的电极构成的元件。充电时，两电极上形成等量异号的电荷，并在电极之间建立电场和电压。电容器可以通过电场储存能量。

电容器通过电荷分离建立电场、储存能量；流过它的电流与两端电压变化的快慢有关。



# 三、参数

- **标称容值与误差**：常见 ±5%、±10%、±20%

- **额定电压**：超过将被击穿

  - MLCC 常见 6.3V、16V、25V、50V

  - 电解电容常见 10V、16V、25V、35V、50V

  - 电容的工作电压不应达到额定电压。一般来说，**实际工作电压不超过额定电压的 50%~80%**：

    - 24V 电路上，陶瓷电容至少选择 **50V** 耐压
    - 12V 电路上，至少选择 **25V**

    此外还需注意 **MLCC 的直流偏压效应**：标称 10µF 的 MLCC，施加额定电压后实际容值可能只剩一半甚至更少。在电源设计中需特别注意这一点。

- **ESR/ESL（等效串联电阻/电感）**：ESR 决定纹波与发热，开关电源的输出电容必须选用**低 ESR** 型号

- **温度特性（介质类型）**：

| 介质类型 | 特点                                     | 用途                 |
| :------- | :--------------------------------------- | :------------------- |
| C0G/NP0  | 最稳定，容值几乎不随温度、电压变化       | 振荡、滤波、精密场合 |
| X7R      | 比较稳定，性价比高                       | 通用滤波、去耦       |
| X5R      | 与 X7R 接近，温度范围略窄                | 通用滤波、去耦       |
| Y5V      | 容量大但温漂非常严重，容值随电压衰减剧烈 | 只用于要求不高的场合 |

电容单位换算:

\[ \mathrm F \rightarrow \mathrm{mF} \rightarrow \mu\mathrm F \rightarrow \mathrm{nF} \rightarrow \mathrm{pF} \]

每向右移动一格，数值乘以 \(1000\)

电容值：\(C=Q/U\)​

# 六、电容的通用特性
## 隔直通交

- 隔直：对理想电容，在**直流稳态**时，两端电压不再变化，因此，理想电容在直流稳态下的电流为零，两端电压不再发生改变，可以等效为开路。故，**理想电容在直流稳态下相当于开路**。
- 通交：交流电压随时间变化。相应地，电容支路可以出现交流电流。

## 电容器上的电压不能突变

- 电压通过电荷积累形成，因此当流过理想电容的电流有限时，电容两端电压不能发生瞬间跳变。

# 七、作用

## 储能

- 电容充电时，电源向电容传递能量，能量以电场形式储存；放电时，电容可以向外部电路释放部分能量。

- 电容通过电场储存能量：

  \[ \boxed{E=\frac12 CU^2} \]

## 滤波

- 电源中的电容用于抑制电压波动：负载突变时由电容先提供瞬时电流，避免电源响应不及导致电压跌落。
- 滤波电路使不同频率的信号受到不同程度的衰减或通过。
- 信号频率越高衰减越大。频率越高，峰值电流越大，缓冲了电压
- 常见滤波器：

  - | 滤波器     | 一般作用趋势                         |
    | ---------- | ------------------------------------ |
    | 低通滤波器 | 低频相对更容易通过，高频受到更大衰减 |
    | 高通滤波器 | 高频相对更容易通过，低频受到更大衰减 |
    | 带通滤波器 | 某个频率范围相对更容易通过           |
    | 带阻滤波器 | 某个频率范围受到更大衰减             |

## 去耦

- 防止噪声产生干扰
- 去耦电容通常接在芯片的电源引脚和地之间，并尽量靠近芯片。
  - 0.1µF 的去耦电容，与芯片电源引脚的距离**越近越好**（几毫米以内）。距离过远时，中间走线的寄生电感会使其失去作用。
  - 大电容与小电容并联使用：大电容抑制低频波动，小电容抑制高频噪声，各司其职。
- **减弱电路模块通过供电网络相互影响**
- 去耦：在芯片的电源引脚附近放置合适的电容，让芯片在电流突然变化时，附近有一个能快速参与供电的“能量缓冲”，从而减小芯片电源引脚处的电压波动。

## 旁路

- 为某些变化信号或干扰电流提供一条替代路径
  - 例如，将电容接在电源和地之间时，对于某些变化较快的电流成分，这颗电容可以参与形成一个**局部电流回路**，让这部分电流不必全部经过较长的供电路径。

- **去耦和旁路是什么关系？**

  两者常使用同一颗电容，只是强调的角度不同：

  - **去耦**：强调减少电源网络中的相互影响；
  - **旁路**：强调给某些变化电流提供局部通路。

# 八、积分电路、微分电路

- 微分电流：输出电压在电阻的两侧：
  - 输出电压近似与输入电压对时间的微分成正比

- 积分电路：输出电压在电容两侧;

  - 输出电压近似与输入电压对时间的积分成正比

- **电容电压与流入电容的电流随时间的累积有关。**

- | 比较           | RC 近似积分电路                  | RC 近似微分电路                  |
  | -------------- | -------------------------------- | -------------------------------- |
  | 基本结构       | 电阻在前，电容接地               | 电容在前，电阻接地               |
  | **输出位置**   | **电容两端**                     | **电阻两端**                     |
  | 对应基本滤波器 | 低通                             | 高通                             |
  | 常见近似条件   | 所关注频率满足 \(\omega RC\gg1\) | 所关注频率满足 \(\omega RC\ll1\) |
  | 数学关系       | 输出近似与输入的积分有关         | 输出近似与输入的微分有关         |
  | 初学图像       | 观察信号的累积效果               | 观察信号变化快慢                 |

# 九、如何选取电容？

看到一颗电容，你可以依次问：

1. **它是什么类型？**陶瓷、电解、薄膜，还是其他？
2. **它有极性吗？**如果有，正负极在哪？
3. **容量多大？**例如 \(100\ \mathrm{nF}\)、\(10\ \mu\mathrm F\)。
4. **额定电压是多少？**适用于什么工作条件？
5. **用在电路哪里？**芯片去耦、电源滤波，还是交流输入？
6. **有没有特殊要求？**例如 ESR、纹波电流、温度、安规认证。

| 参数       | 需要理解的内容                         |
| ---------- | -------------------------------------- |
| 标称电容值 | 器件标注的容量                         |
| 容差       | 实际值相对于标称值允许有多大偏差       |
| 额定电压   | 器件允许工作的电压条件，需结合手册     |
| 极性       | 是否必须区分正负极                     |
| ESR        | 等效串联电阻，可能影响损耗、纹波和发热 |
| 温度特性   | 电容值等参数随温度变化的情况           |
| 频率特性   | 不同频率下电容的实际表现可能不同       |
