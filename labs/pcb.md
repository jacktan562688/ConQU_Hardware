# RC 低通练习板 · 设计与验收

沿用 C1/C2 的 1 kΩ 和 100 nF。原理图是 VIN 经 R1 到 VOUT，C1 从 VOUT 到 GND。用输入/输出连接器分别引出信号和地，保留 VIN、VOUT、GND 测点。采用双层练习板。实际器件封装以所选元件规格为准。电容输出由高阻仪表或仿真探头观察，有负载时另记负载阻抗。

## 设计检查

- [ ] 标明输入、输出、地，记录元件取值及所选封装。
- [ ] 核对连接器顺序、焊盘编号、封装尺寸、器件位号和接线标识。
- [ ] 保存原理图检查结果，逐项解释处理过的警告。
- [ ] 板框闭合。布局能插接和测量，观察信号路径及地回路。
- [ ] 对照厂商工艺填写选用线宽、间距、孔径、环宽、铜到板边，注明层数和铜厚。
- [ ] 完成走线和地铜，检查飞线、孤岛、丝印和 DRC。归档检查截图。
- [ ] 导出并预览顶底铜、阻焊、丝印、板框和钻孔。逐个确认接口、板边和孔位。
- [ ] 保存源工程、Gerber/钻孔包及预览截图，记录版本日期、已知问题和改动。

## 月末口头验收

用 3 分钟沿输入端到输出端讲一遍。说明电阻、电容在时域和频域分别做了什么，RC 参数改一倍波形怎么变。指出一处可制造性约束，再说明 DRC 之外为何还要看引脚映射与制造层。最后对照 STM32 的功能框图，说明 MCU 板会增加哪些供电、复位、启动、时钟和调试需求。交付到制造文件预览即可。
